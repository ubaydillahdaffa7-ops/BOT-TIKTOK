PLATFORM 02 / TELEGRAM

Konfigurasi Bot Telegram

Sambungkan bot Telegram ke mesin perintah dan katalog DAFZZ.

BELUM DIATUR

Status Telegram

Token belum disimpan dan bot belum terhubung.

USERNAMEBelum terdeteksi

Cara mendapatkan token

Buka Telegram, cari akun resmi @BotFather, kirim /newbot, ikuti instruksinya, lalu salin token yang diberikan. Token itu memberi kendali penuh atas bot, jadi jangan bagikan kepada orang lain.

Buka BotFather

Data koneksi Telegram

Token disimpan di server. Nilainya tidak akan ditampilkan kembali setelah disimpan.

Kosongkan jika token yang tersimpan tidak ingin diganti.

Aktifkan bot Telegram

Bot akan menerima pesan pribadi dan membalas lewat Telegram.

Pengguna harus membuka chat bot dan menekan Start terlebih dahulu. Bot ini menggunakan long polling; webhook lama pada token yang sama akan dihapus ketika koneksi diaktifkan agar polling dapat berjalan. Pada Render Free, proses dapat tidur saat tidak ada trafik masuk sehingga bot tidak dijamin online 24 jam.

PANDUAN PENGGUNAAN

Setelah token disimpan

  1. Simpan token dari @BotFather pada kolom di atas.
  2. Tekan Periksa token untuk memastikan token diterima Telegram.
  3. Aktifkan bot dan tunggu status berubah menjadi TERHUBUNG.
  4. Buka tautan bot yang ditampilkan BotFather, lalu tekan Start.
  5. Kirim .menu untuk daftar fitur atau .ai pertanyaan kamu untuk bicara dengan AI.

PLATFORM 03 / WHATSAPP

Konfigurasi Bot WhatsApp

Tautkan akun melalui pairing code atau QR dari WhatsApp pada ponsel.

BELUM DITAUTKAN

Status WhatsApp

Belum ada sesi WhatsApp yang aktif.

AKUN TERTAUTBelum terdeteksi

Jenis koneksi

Koneksi menggunakan Baileys, yaitu library komunitas yang berkomunikasi melalui WhatsApp Web. Library ini bukan layanan resmi WhatsApp dan akun dapat terkena pembatasan. Gunakan akun milik sendiri dan pahami risikonya sebelum menautkan.

Dokumentasi Baileys

Tautkan nomor WhatsApp

Masukkan nomor dengan kode negara, tanpa tanda plus atau spasi. Contoh Indonesia: 6281234567890.

KODE TAUTAN WHATSAPP

------

Di ponsel buka WhatsApp → Perangkat tertaut → Tautkan perangkat → Tautkan dengan nomor telepon, lalu masukkan kode di atas.

Sesi WhatsApp disimpan di folder data privat server. Render Free dapat sleep setelah tidak menerima trafik masuk, dan tidak menyediakan persistent disk. Saat sleep, koneksi Telegram/WhatsApp bisa terputus; file konfigurasi dan sesi lokal dapat hilang ketika service di-restart atau di-deploy ulang. Bot yang harus aktif terus-menerus memerlukan host yang selalu menyala serta penyimpanan persisten.

PANDUAN PENYAMBUNGAN

Langkah menautkan akun

  1. Pastikan nomor WhatsApp adalah akun milikmu sendiri.
  2. Masukkan nomor lengkap dengan kode negara, misalnya 62812xxxxxxxx.
  3. Tekan Minta kode tautan dan selesaikan lima persetujuan risiko yang ditampilkan.
  4. Di WhatsApp, buka Perangkat tertaut → Tautkan perangkat → Tautkan dengan nomor telepon.
  5. Masukkan kode dari halaman DAFZZ. Tunggu sampai status berubah menjadi TERHUBUNG.
  6. Untuk mulai menguji, kirim .menu atau .ai halo ke nomor WhatsApp yang tertaut dari akun lain.

Jangan bagikan kode tautan, QR, maupun folder sesi kepada siapa pun. Jika ingin memutuskan koneksi, gunakan tombol Hapus sesi dan keluar.

PENYAMBUNGAN AKUN

Langkah impor sesi TikTok

  1. Jalankan bridge TikTok pada server dengan Docker Compose.
  2. Login ke akun TikTok milikmu melalui Chrome desktop dan buka inbox.
  3. Ikuti panduan upstream untuk mengekspor request inbox dan socket ke dua file lokal. File itu berisi data sesi akun, jadi jangan unggah ke chat, repository, atau website pihak lain.
  4. Impor dua file tersebut melalui perintah bridge di server. Setelah selesai, ambil API token dan webhook secret melalui perintah CLI bridge.
  5. Masukkan token dan webhook secret ke bagian Konfigurasi bridge di atas, lalu uji koneksi.

Panel ini tidak meminta password TikTok. Koneksi dilakukan dengan mengimpor sesi akun milikmu sendiri dari Chrome desktop ke bridge yang berjalan di server. Konektor ini hanya mendukung percakapan satu lawan satu yang sudah ada dan pesan teks. Login QR, pembaruan sesi otomatis, permintaan DM baru, serta kirim/terima media belum didukung.

PERSETUJUAN SEBELUM PEMASANGAN

Baca lima peringatan ini

0 dari 5 dipahami
01

Aturan dan pembatasan platform

Setiap platform punya ketentuan penggunaan sendiri. Koneksi WhatsApp melalui Baileys bukan integrasi resmi WhatsApp. Otomatisasi yang dianggap tidak wajar, penggunaan TikTok DM Bridge, atau pengaturan bot yang melanggar ketentuan dapat membuat fitur dibatasi, sesi diputus, nomor diblokir, atau akun terkena tindakan dari platform. Tidak ada jaminan akun akan aman hanya karena koneksi berhasil.

02

Akses akun, token, QR, dan kode tautan

Token Telegram, QR WhatsApp, pairing code, cookie, access key, dan berkas sesi adalah kunci akses akun atau bot. Orang yang mendapatkannya bisa mengambil alih koneksi atau mengirim pesan sebagai bot. Jangan kirim data tersebut ke orang lain, jangan memasukkannya ke repository publik, dan gunakan hanya akun yang kamu miliki atau berwenang kelola.

03

Spam, pesan otomatis, dan izin penerima

Balasan otomatis yang terlalu sering, pesan massal tanpa izin, promosi berulang, atau pesan yang mengganggu penerima dapat dilaporkan dan memicu pembatasan. Bot DAFZZ ditujukan untuk membalas pesan yang diterima dan menjalankan perintah yang diminta. Jangan menggunakannya untuk spam, penipuan, pelecehan, pengiriman massal, atau menghubungi orang yang tidak menyetujui pesan tersebut.

04

Privasi pesan dan pemrosesan AI

Pesan yang masuk diproses oleh server DAFZZ. Jika AI menjawab, isi pertanyaan dapat diteruskan ke penyedia AI pihak ketiga yang dipakai saat itu. Pada layanan komunitas atau anonim, operator dan pekerja layanan mungkin dapat melihat prompt. Jangan kirim kata sandi, OTP, data kartu, dokumen pribadi, cookie, token, atau informasi rahasia melalui bot.

05

Gangguan, kuota gratis, dan kehilangan sesi

Server hosting, internet, bridge, library, dan penyedia AI bisa berhenti, membatasi kuota, mengganti API, atau mengubah aturan sewaktu-waktu. Server restart atau penyimpanan yang tidak persisten dapat memutus sesi dan membuat akun perlu ditautkan ulang. Pesan dapat terlambat, tidak terkirim, atau gagal diproses. Pengelola DAFZZ tidak menjamin layanan selalu aktif, selalu gratis, atau selalu berhasil.

Tombol lanjut akan aktif setelah kelima tombol Paham ditekan. Persetujuan berlaku untuk proses pemasangan platform yang sedang dipilih.
