PENYAMBUNGAN AKUN

Langkah impor sesi TikTok

  1. Jalankan bridge TikTok pada server dengan Docker Compose.
  2. Login ke akun TikTok milikmu melalui Chrome desktop dan buka inbox.
  3. Ikuti panduan upstream untuk mengekspor request inbox dan socket ke dua file lokal. File itu berisi data sesi akun, jadi jangan unggah ke chat, repository, atau website pihak lain.
  4. Impor dua file tersebut melalui perintah bridge di server. Setelah selesai, ambil API token dan webhook secret melalui perintah CLI bridge.
  5. Masukkan token dan webhook secret ke bagian Konfigurasi bridge di atas, lalu uji koneksi.

Panel ini tidak meminta password TikTok. Koneksi dilakukan dengan mengimpor sesi akun milikmu sendiri dari Chrome desktop ke bridge yang berjalan di server. Konektor ini hanya mendukung percakapan satu lawan satu yang sudah ada dan pesan teks. Login QR, pembaruan sesi otomatis, permintaan DM baru, serta kirim/terima media belum didukung.
