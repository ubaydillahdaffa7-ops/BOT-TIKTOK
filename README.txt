DAFZZ-TOOLS + TIKTOK BOT
========================

Website DAFZZ-TOOLS mempertahankan tampilan, stylesheet, script, dan katalog
sumber. Katalog aktual pada tools.json terdiri dari 300 tool dalam enam kategori,
masing-masing 50 tool. README dan laporan QA pada arsip website awal sempat
menyebut tujuh kategori; angka tersebut tidak sesuai dengan tools.json aktual.

Untuk instalasi bot, integrasi TikTok, panel admin, AI fallback, domain HTTPS,
dan halaman download, baca README.md pada folder utama paket.

Fungsi browser dari website dipakai kembali pada halaman /run/<token>. Hasil yang
dibuat melalui fungsi result standar diunggah sementara ke server agar tautan
unduhan dapat dibalas melalui DM. File yang dikirim langsung sebagai lampiran
DM TikTok tidak didukung oleh bridge saat ini.
